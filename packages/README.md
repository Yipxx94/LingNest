## 安全提示

- 当前软件包尚未进行代码签名，Windows 可能显示信誉提示。
- 不要从仓库的 `build/` 目录下载或单独复制开发构建的 EXE。
- 软件包不包含用户配置、API Key、数据库、日志或调试符号。
