# LingNest v0.1.2 用户指南

## 安装与启动

LingNest v0.1.2 支持 Windows 10/11 x64。推荐双击 `LingNest-v0.1.2-windows-x64-setup.exe` 安装；安装程序会把应用、Qt 运行库、Qt 插件、角色资源和 VC++ 运行库一起放到正确位置，并创建开始菜单入口。

若使用便携 ZIP，必须先把 ZIP 完整解压到一个可写目录，再双击解压目录中的 `LingNest.exe`。不要在压缩包预览窗口中直接运行，也不要只把 EXE 单独复制到其他电脑；依赖文件和目录需要保持原有相对位置。仓库 `build/release/` 下的同名 EXE 是开发构建产物，不是发布包。

Windows 首次运行未签名的测试版本时可能显示安全提示。请只使用项目发布目录中的包，并先核对随包提供的 SHA-256。

同一 Windows 用户会话只允许运行一个 LingNest 实例。重复双击不会创建第二个桌宠。

## 基本操作

- 将鼠标移到桌宠上：显示底部的对话与快速回应按钮。
- 单击桌宠：触发本地开心反馈。
- 双击桌宠：打开贴近桌宠的单行输入条。
- 拖动桌宠：平滑移动并自动保存位置。
- 右键桌宠：打开冷白半透明菜单，可进入设置、预览动作、暂停活动或退出。
- 任务栏通知区域图标：单击唤回桌宠，双击进入对话，右键可显示/隐藏、设置或退出。

输入条中按 Enter 发送，按 Esc 收起。发送后桌宠会先进入思考状态，再用气泡直接回答。

## 配置 AI 服务

打开“设置”，填写 OpenAI-compatible 服务的 Base URL、模型名称、Temperature、Max Tokens、超时和 API Key。Base URL 可填写服务根路径（例如以 `/v1` 结尾），LingNest 会自动追加 `/chat/completions`。

非敏感参数保存在本机配置文件中。API Key 只写入 Windows 凭据管理器，目标名为 `LingNest/OpenAICompatible/default`，不会写入配置文件或发布包。

未配置 AI、断网或服务不可用时，桌宠动画和本地互动仍可使用；对话气泡会显示可理解的错误信息。

## 本地数据

默认情况下，配置、对话与长期记忆位于当前用户的 LingNest 应用数据目录（通常是 `%LOCALAPPDATA%\LingNest\LingNest\`）：

- `config.json`：窗口位置与非敏感 AI 参数。
- `memory.sqlite3`：对话、长期记忆与用户资料。

若配置或数据库被明确判定为损坏，LingNest 会保留一个带 `.corrupt-时间戳` 后缀的原文件，并创建干净文件继续启动。可将该备份交给开发者分析，其中可能包含本地设置或聊天内容，请勿公开上传。

## 退出与卸载

请使用桌宠或通知区域菜单中的“退出”，确保位置和数据库正常关闭。安装版可在 Windows“已安装的应用”中卸载；便携版先退出程序，再删除完整解压目录。

若还要清除个人数据，请另外删除 LingNest 应用数据目录，并在 Windows“凭据管理器”中删除 `LingNest/OpenAICompatible/default`。这些操作不可恢复，执行前请自行备份需要保留的内容。

## 故障排查

- 桌宠不见了：单击通知区域的 LingNest 图标；程序会把窗口恢复到当前可用屏幕区域。
- 对话失败：检查 Base URL、模型、API Key、网络与服务兼容性。
- 无法启动：优先重新运行 `*-setup.exe`；使用便携版时，确认已完整解压 ZIP，并保留 `platforms`、`qml`、Qt DLL 与 `characters` 目录。
- 需要报告问题：提供版本号、Windows 版本和复现步骤。不要发送 API Key；发送 `.corrupt-*` 文件前先确认其中没有不愿分享的个人信息。
