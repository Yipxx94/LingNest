# LingNest v0.1.0 发布说明

发布日期：2026-09-18  
平台：Windows 10/11 x64  
形式：免安装便携 ZIP

这是 LingNest 的首个 MVP 发布候选。它提供多角色桌宠框架和首个角色“渝爱”，包含透明桌宠窗口、九类动画状态、平滑拖动、桌面边界适配、单实例、通知区域入口、Liquid Glass 风格交互、OpenAI-compatible 对话、Windows 凭据存储与 SQLite 长期记忆。

本版本新增发布稳定性加固：

- EXE 写入正式的 `0.1.0` 文件与产品版本资源，并统一应用、窗口和通知区域图标。
- 损坏 JSON 配置自动备份并恢复默认配置。
- SQLite 启动时执行完整性快速检查；确认损坏后备份原库并建立干净数据库。
- 服务端错误意外回显当前 API Key 时进行脱敏。
- 使用 `windeployqt` 生成自包含运行目录，并对敏感文件和开发文件做发布门禁。
- VC++ 运行库采用应用本地部署，不要求用户先运行额外安装器。
- 同时生成 ZIP、SHA-256 和机器可读发布清单。

已知限制：

- 这是未进行代码签名的首版测试包，Windows 可能显示信誉提示。
- 本机发布工具链为 Qt 5.15.2 兼容构建。Qt 5 的 HTTPS 需要已停止维护的 OpenSSL 1.1.1，因此本包未从其他软件捆绑该 DLL；本地 HTTP 兼容服务可用，正式公网 HTTPS 包计划切换到 Qt 6。
- 真实双显示器热插拔和完全干净的 Windows 设备仍应作为发布签收项进行人工复核。
- 语音、屏幕理解、复杂 Agent、插件市场和角色商店不属于本轮 MVP。
