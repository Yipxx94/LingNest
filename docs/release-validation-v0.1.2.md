# LingNest v0.1.2 发布验证记录

验证日期：2026-09-21
构建平台：Windows x64
编译器：MSVC 19.44
兼容运行时：Qt 5.15.2

## 已通过

- Debug 自动化测试：15/15。
- Release 自动化测试：15/15。
- 右键主菜单的“退出 LingNest”和动作预览页的“睡觉”完整位于圆角卡片内，底部保留安全间距。
- 主菜单六个操作行之间的间距均为 2 像素，对话输入区移除左侧冗余加号后已验证靠左布局。
- 菜单项悬停高亮持续停留 300 毫秒仍保持，鼠标移开后才消退；自动化测试同时检查背景色。
- 模拟系统原生拖动越过屏幕左、右、上、下四边，松手后实际窗口均回到可用工作区。
- 右键菜单在左键点击桌宠及切换到另一窗口后自动关闭；应用失活时的关闭逻辑已接入。
- 对话输入后，发送按钮启用状态的深蓝背景及加粗箭头已截图检查。
- AI 设置窗在桌宠位于屏幕四角时仍完整落在可用工作区内；标题栏拖动、右上角关闭、较矮视口滚动和保存输入校验通过 UI 回归测试。
- AI 设置窗的冷白玻璃、圆角、文本层级和底部操作区已截图人工检查。
- 桌宠位于屏幕右下角时，主菜单及动作预览页均位于屏幕可用工作区内。
- 主菜单、动作预览页与对话输入条截图人工检查：布局完整且最末项文字与背景完整显示。
- 便携部署目录在清理 Qt 环境变量和 PATH 后启动烟雾测试：退出码 0。
- 安装程序与便携 ZIP 的版本资源、Qt/VC++ 依赖、SHA-256 和发布清单核对通过。
- 发布扫描未发现 API Key、用户配置、数据库、日志或开发调试文件。

## 待跨环境签收

- 当前受管测试环境没有 Explorer 桌面窗口；右键菜单在真实桌面空白处点击后的收起行为需在正常 Windows 桌面复核。
- 当前构建机的受管自动化执行环境会阻止新生成的安装类 EXE 创建进程，因此安装与卸载仍需在一台干净的 Windows 10/11 x64 设备上签收。
- 本机发布工具链仍为 Qt 5.15.2 兼容构建。公网 HTTPS 需要已停止维护的 OpenSSL 1.1.1，联网使用前需切换 Qt 6 并重新验证。
- 后续仍需完成代码签名、双显示器/不同缩放比例实机验证，以及角色和参考素材授权确认。GitHub Release 已创建不代表这些事项已签收。
