# LingNest v0.1.1 发布验证记录

验证日期：2026-09-19  
构建平台：Windows x64  
编译器：MSVC 19.44

## 已通过

- Release 全量自动化测试：15/15。
- 便携目录在清理后的运行环境中完成启动烟雾测试：退出码 0。
- 单文件安装程序由 Inno Setup 6.7.3 编译成功，版本资源、输出名称、文件大小与 SHA-256 均已校验。
- EXE 文件版本、产品版本与应用版本：`0.1.1`。
- 安装程序和应用 EXE 使用 `resources/icons/lingnest.ico`。
- 从安装程序与应用 EXE 提取的关联图标像素哈希一致。
- 安装源目录包含 Qt 运行库、QML 模块、`platforms/qwindows.dll`、SQLite 插件、VC++ x64 运行库和角色资源；安装器从该目录递归收录文件。
- 安装脚本采用当前用户目录与最低权限模式，不要求管理员权限；安装源目录已包含所有运行依赖，不要求用户预装 Qt 或 Visual Studio。
- 发布扫描未发现 API Key、`config.json`、`memory.sqlite3`、日志、PDB、LIB、PEM 或 KEY 文件。
- 安装程序与便携 ZIP 的 SHA-256 均有独立校验文件，且摘要与发布清单一致。

## 待人工跨环境签收

- 当前构建机的受管自动化执行环境会阻止新生成的安装类 EXE 创建进程，因此安装/卸载自动化烟雾测试未在该环境伪造通过。需在一台从未安装 Qt、Visual Studio 和 LingNest 的干净 Windows 10/11 x64 设备上运行安装程序、启动应用并完成卸载签收。
- 在双显示器、不同缩放比例及热插拔场景下复核位置恢复与菜单钳制。
- 使用 Qt 6 正式工具链重建，验证系统 TLS/HTTPS 后再作为公网联网发行包。
- 正式公开发布前完成代码签名和角色/参考素材授权确认。
