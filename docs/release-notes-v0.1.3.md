# LingNest v0.1.3 发布说明

日期：2026-09-28
平台：Windows 10/11 x64

本次修复右键菜单切换选项时短暂出现两个高亮的问题。菜单项在鼠标移入时立即显示选中背景，移出时立即清除；键盘焦点不再让另一项留下类似悬停的描边。鼠标停在某一项时，高亮仍会一直保持到移开。

菜单选中背景改为与冷白玻璃面板区分明显的浅蓝色。桌宠下方的对话与快速回应按钮共用稳定的悬停保持状态：鼠标越过中间分隔线时，整个操作栏不会反复隐藏、重现或闪烁；鼠标真正离开后才延时收起。

首次通过桌宠下方的对话按钮打开输入条时，输入条现在会在窗口显示后再请求激活，并在应用切到其他窗口时主动收起。再次打开对话条沿用同一套行为。

版本号更新为 `0.1.3`。[GitHub Release](https://github.com/Yipxx94/LingNest/releases/tag/v0.1.3) 已提供安装程序、便携 ZIP、校验文件和发布清单。安装程序与便携 ZIP 仍包含 Qt、插件、角色资源及应用本地 VC++ 运行库。

验证结果与剩余实机签收项见 [验证记录](release-validation-v0.1.3.md)。
