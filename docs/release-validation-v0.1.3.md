# LingNest v0.1.3 发布验证记录

验证日期：2026-09-28
构建平台：Windows x64
编译器：MSVC 19.44
兼容运行时：Qt 5.15.2

## 已通过

- Debug 自动化测试：15/15。
- Release 自动化测试：15/15。
- 右键菜单逐项移动时，每一刻只保留当前选项的背景高亮；停留 300 毫秒保持，移出后立即清除。已检查“开始对话”和“AI 设置”的悬停截图。
- 菜单选中背景使用可辨识的浅蓝色；“开始对话”和“AI 设置”截图显示选中态与白色玻璃面板有清晰区分。
- 鼠标在底部对话按钮、分隔线和快速回应按钮之间往返时，操作栏始终可见，玻璃高亮保持稳定；回归测试检查窗口没有隐藏事件。
- 模拟首次从桌宠下方按钮打开对话条、其他窗口取得焦点、再次打开的流程；输入条均能正常收起。
- 本地便携部署目录在清理 Qt 环境变量和 PATH 后通过启动烟雾测试。
- 本地安装程序与便携 ZIP 的版本、依赖、SHA-256 和发布清单核对通过。

## 待实机签收

- 当前受管测试环境没有 Explorer 桌面窗口；首次打开对话条后点击真实桌面空白处的收起行为，仍需在正常桌面复核。
- 安装与卸载、双显示器和不同缩放比例仍需在干净 Windows 10/11 x64 设备上复核。
- 公网 HTTPS、代码签名以及角色和参考素材授权仍沿用 `0.1.2` 的待签收限制。

本版本的 [GitHub Release](https://github.com/Yipxx94/LingNest/releases/tag/v0.1.3) 已提供安装程序与便携 ZIP；发布不代表上述跨环境事项已完成签收。
