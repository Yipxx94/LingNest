# LingNest v0.1.2 发布说明

发布日期：2026-09-21
平台：Windows 10/11 x64
形式：单文件安装程序（推荐）与便携 ZIP

v0.1.2 修复桌宠右键菜单最下面一栏显示不完整的问题。菜单现在根据实际内容高度确定窗口大小，为圆角玻璃卡片底部留出空间；在桌面边缘打开或切换到“动作预览”页时，也会按最终窗口尺寸重新约束到屏幕工作区内。

候选包进一步统一了主菜单各操作行的间距，去掉“切换角色”与“暂停活动”之间过宽的留白。对话输入条移除了没有独立用途的左侧加号，让输入区更简洁，也为文字留出更多空间。右键菜单现在会在左键点桌宠或应用切到桌面及其他窗口时收起；输入文字后，发送按钮使用更清晰的粗箭头与更深的蓝色。版本号仍为 `0.1.2`。

AI 设置窗现在与右键菜单使用同一套冷白半透明玻璃表面、圆角和蓝色强调色。打开时按桌宠所在屏幕的可用区域定位，桌宠靠近任意桌面边缘也不会把设置窗挤出屏幕；标题栏可拖动，右上角和底部均可关闭。较矮屏幕上表单可滚动，底部操作区仍保持可见。本地修改不增加版本号。

右键菜单行的悬停高亮改由独立的指针跟踪保持：鼠标停在选项上时不会短暂出现后自行消失，移出选项后才淡出。系统拖动桌宠越过屏幕左、右、上、下边界时，松开鼠标会把实际窗口弹回可用工作区，避免仅保存了正确坐标而当前桌宠仍停在屏幕外。本次修复仍使用 `0.1.2` 版本号。

主菜单与动作预览页都增加了针对最后一项可见性和边界位置的回归测试，主菜单还验证所有操作行的间距一致，并覆盖点击桌宠、切换窗口后的菜单关闭行为。应用功能与 v0.1.1 保持兼容，安装程序和便携 ZIP 继续包含 Qt、插件、角色资源与应用本地 VC++ 运行库。

已知限制与正式公开发行前的签收项见 [发布验证记录](release-validation-v0.1.2.md)。
