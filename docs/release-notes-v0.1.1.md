# LingNest v0.1.1 发布说明

发布日期：2026-09-19  
平台：Windows 10/11 x64  
形式：单文件安装程序（推荐）与便携 ZIP

v0.1.1 是首个发布包的交付修正版。应用功能与 v0.1.0 保持兼容，重点解决将裸 `LingNest.exe` 复制到其他电脑后缺少 Qt DLL 的问题。

本版本改进：

- 新增基于 Inno Setup 6 的单文件 `setup.exe`，安装时一次性部署应用、Qt DLL、QML 模块、平台与数据库插件、角色资源和应用本地 VC++ 运行库。
- 安装程序与应用使用同一 LingNest 品牌图标，提供开始菜单入口、可选桌面快捷方式和标准卸载入口。
- 安装位置默认位于当前用户目录，不需要管理员权限。
- 仓库根目录新增明确的 `dist/` 交付目录，避免把 `build/release/LingNest.exe` 误认为可单独分发的软件。
- 继续提供完整便携 ZIP，并在交付说明中明确要求先完整解压，禁止从 ZIP 预览窗口直接启动或只复制 EXE。
- 安装程序与便携 ZIP 分别生成 SHA-256；发布清单记录推荐产物、版本、大小和摘要。

已知限制：

- 当前包尚未进行代码签名，Windows 可能显示信誉提示。
- 本机发布工具链仍为 Qt 5.15.2 兼容构建。Qt 5 的公网 HTTPS 依赖已经停止维护的 OpenSSL 1.1.1，因此本项目不会从其他软件目录拼装该依赖；本地 HTTP 兼容服务与其他桌宠能力不受影响，正式公网 HTTPS 发行仍需切换 Qt 6。
- 正式公开或商业发布前仍需完成代码签名、干净 Windows 实机签收，以及角色和参考素材授权确认。
