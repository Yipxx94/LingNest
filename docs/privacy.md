# LingNest v0.1.2 隐私说明

更新日期：2026-09-21

LingNest v0.1.2 不包含账号系统、遥测、广告或后台分析服务。应用核心功能在本机运行；只有当用户主动发送对话且已经配置 AI 服务时，才会访问所配置的第三方接口。

## 本机保存的数据

- 窗口位置与非敏感 AI 参数保存在 `config.json`。
- 对话内容、用户明确要求“记住”的内容和由此提取的用户资料保存在 `memory.sqlite3`。
- API Key 保存在 Windows 凭据管理器，目标名为 `LingNest/OpenAICompatible/default`。
- 损坏恢复可能产生 `.corrupt-时间戳` 备份；备份可能包含原配置或聊天数据。

LingNest 当前不主动上传这些本地文件，也不生成持久化诊断日志。控制台错误不记录请求正文，并会从服务端错误文本中移除当前 API Key 的明文回显。

## 发送给 AI 服务的数据

用户按 Enter 发送消息时，LingNest 会把以下内容发送到设置中指定的 OpenAI-compatible 地址：角色人格提示词、相关长期记忆与用户资料、最近对话、本轮消息、模型参数，以及用于鉴权的 API Key。服务提供方如何保存和处理这些数据取决于其自身条款和隐私政策。

LingNest 不会因待机、走动、眨眼、睡眠、拖动、菜单操作或其他本地动作调用 AI 服务。

## 用户控制

用户可以在设置中删除已保存的 API Key，可以清除对话，也可以退出应用后删除本地数据目录。清除对话不会自动删除用户明确要求长期保存的记忆；若要彻底清除，应删除本地数据库。

公开分享配置、数据库或损坏备份前，请先检查其中是否含有个人信息。发布安装程序与 ZIP 均不包含开发机的 API Key、配置、数据库或日志。
