# 渝爱角色视觉规范

## 视觉定位

半写实、柔和绘制的真实大熊猫桌宠。允许为小尺寸显示简化毛发与轮廓，但不得改造成大头幼崽、毛绒玩具、二次元熊猫或通用卡通熊猫。

## 身份锚点

| 部位 | 必须保持的特征 |
| --- | --- |
| 脸型 | 白色脸盘宽、圆、饱满，双颊外扩且毛量充足；下颌轮廓圆润，不做尖下巴。 |
| 耳朵 | 黑色、近圆、小而高位，位于头顶左右；不能放大成米奇式大耳，也不能改成尖耳。 |
| 眼睛 | 深色眼睛偏小、温柔灵动，目光通常正视或轻微侧看；不能改成夸张大眼或高亮动漫眼。 |
| 黑眼圈 | 纵向水滴/窄梨形，由眼周向下延伸；左右总体对称，但保留真实毛发边缘，不画成规整椭圆贴纸。 |
| 鼻口 | 白色鼻梁短而宽，黑鼻紧凑、略呈圆角三角；口部小，常有轻微笑意，开心时可自然张口。 |
| 黑白区域 | 头脸与躯干主体为暖白/乳白；耳、眼斑、肩带、四肢为黑；肩部黑带必须清晰，腹胸可见暖灰白毛。 |
| 体型 | 敦实、圆重、肩背宽，四肢粗短有力量；坐姿呈稳定三角轮廓，四足行走时背线圆而平缓。 |
| 毛发 | 真实密绒感，白毛略暖，黑毛不是纯平涂；小尺寸时可减细节，但边缘仍应自然、清晰、无光晕。 |
| 爪部 | 黑色粗壮前后肢，爪尖可少量可见；避免夸张锐利或人手化。 |

## 服装、配饰与道具

- 基础身份没有固定服装、项圈、帽子或饰品。
- 竹子、胡萝卜、玩偶、篮子、小黄鸭等是照片中的临时道具，不进入默认角色设计。
- 若以后做节日皮肤，道具必须单独作为 skin/variant，不得反向污染基础动作。

## 常见姿态

- 正面坐姿：最适合作为 idle、blink、talk、thinking、wave 与 avatar 的基础。
- 四足缓步：体态沉稳、步幅不大，适合 walk_left / walk_right。
- 开心张口：嘴部自然张开，可见舌头与少量牙齿，眼睛仍保持真实比例。
- 抬单侧前爪：适合挥手，但不加动作线或漂浮装饰。
- 正面低趴：头部压低到两只前爪之间或其上，前爪在脸颊两侧形成稳定托底；肩背宽厚、躯干向后延伸，不能只剩一个脱离身体的圆头。适合 `daze_prone`。
- 蜷卧/侧卧：适合 sleep，保持圆重体积感，不能缩成玩具团子。

## 不可接受的漂移

- 头身比突然变成 Q 版或幼崽比例。
- 眼斑变成宽椭圆、心形、眉毛或对称贴纸。
- 耳朵显著变大、变尖或位置下降。
- 眼睛放大、增加眼白、睫毛或动漫高光。
- 增加固定胡萝卜、竹子、围巾、项圈、徽章等。
- 加文字、气泡、星星、速度线、地面阴影、光晕或场景。
- 动作之间脸型、耳位、肩带或体型发生明显变化。

## 色彩与边缘

- 输出色彩空间：sRGB。
- 白毛建议范围：暖白到浅奶油色，不漂成纯冷白。
- 黑毛建议范围：近黑到深炭黑，保留微弱毛发层次。
- 所有外部像素必须透明；透明区 RGB 应清空，避免 QML 双线性缩放时出现黑边或彩边。
